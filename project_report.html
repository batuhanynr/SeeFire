🧠 M6: Karar Motoru

5-State FSM ile Otonom Karar

# State Machine Flow INIT → NAVIGATE → VERIFY → ALARM → STOP → NAVIGATE

NAVIGATE

Normal sürüş, waypoint takibi

VERIFY

Fusion score ile yangın teyidi

ALARM

M7 log + trigger, bildirim

STOP

Güvenli duruş, cleanup

📷 Kamera-Free Mod: nav_no_cam.py

Ultrasonik Sadece Engel Geçme

Kamera yokken de çalışır — sadece ultrasonik sensörlerle engel geçme

# 3-Layer Öncelik Sistemi 1. Ön < 60cm → Dur → Bypass 2. Yan < 20cm → 8° mikro düzeltme 3. Ön 600+cm → Çaprazlık kontrolü 4. 15sn → Sağ/sol tarama
